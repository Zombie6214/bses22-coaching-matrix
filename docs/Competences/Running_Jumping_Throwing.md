<h1 style="font-weight: 500; color: var(--md-primary-fg-color)">Running, Jumping, Throwing</h1>

The students develop basic skills in running, jumping, and throwing into athletic disciplines. They practice sprinting and long-distance running, running over obstacles, and cross-country running. They learn to jump wide and high, as well as to throw and push objects far and target. They observe their progress and reflect on their personal abilities and limitations. 

## Running
The students are able to run fast, rhythmically, over obstacles, for long distances, and with spatial orientation. They know the key factors that influence performance and understand how to improve their running abilities.

### Fast Running

- First Cycle:
    - Fast running
    - Run fast on the balls of the feet
    - Start from different positions and run on max speed for short distance
- Second Cycle:
    - Identify and apply important features of sprinting technique
    - Run fast on the balls of the feet over low obstacles
- Third Cycle:
    - Run fast and rhytmic on the balls of the feet over obstacles
    - Apply important features of sprinting techniques when running hurdles

### Endurance Running
- First Cycle:
    - Recognize the own effort and rest periods
    - Run intensely again after short recovery breaks
    - Describe how effort and recovery feel in the body after intense running
- Second Cycle:
    - Adjust their running speed during a prolonged run
    - Run for as many minutes as their age and understand that regular training is crucial for improving performance
- Third Cycle:
    - Run for as many minutes as their age. They can explain how endurance is trained and understand the processes that occur in the body
    - Explain and perform different endurance training methods and justify their performance development


### Orientation
- First Cycle:
    - Navigate independently in the gymnasium and on the school playground
    - Orient while running on the school grounds
    - Navigate while running using orientation aids
- Second Cycle:
    - Navigate the school grounds while running using a map
    - Navigate in the school community while running using a map
- Third Cycle:
    - Follow a route using a map in terrain or forest areas
    - Explain what to pay attention to when using a map for navigation and apply this knowledge in orienteering


## Jumping
The students can jump in various ways, both far and high. They know the key factors that influence performance and can realistically assess their own abilities. 

### Rhytmical Jumping
- First Cycle:
    - Hop rhythmically
    - Perform various hopping and jumping styles using equipment/materials
    - Jump rope
- Second Cycle:
    - Perform various tricks with the jump rope
- Third Cycle:
    - Combine different hopping and jumping sequences, both with and without equipment
    - Teach jumps and tricks to classmates

### Long Jumping
- First Cycle:
    - Jump for distance on one leg and both legs
    - Take off with the right and left leg when running up
- Second Cycle:
    - Cover a distance using multiple jumps
    - Identify key elements of long jump technique and perform take-offs and jumps for distance using both the right and left leg
    - Convert their approach speed into a long jump
- Third Cycle:
    - Apply key elements of long jump technique
    - Observe key elements of long jump technique in classmates and provide feedback

### High Jumping
- First Cycle:
    - Jump vertically on one leg and both legs
    - Run up and jump over low obstacles using both the right and left leg for take-off
- Second Cycle:
    - Jump vertically with an upright torso and a clear swinging leg action, taking off with both the right and left leg
    - Identify key elements of vertical jumping, take off with both the right and left leg, and perform a high jump technique
- Third Cycle:
    - Apply key elements of a high jump technique and realistically assess their own performance
    - Observe key elements of high jump technique in their classmates and provide feedback


## Throwing
The students can throw, push, and hurl objects over long distances and know the key factors that influence performance.

### Throwing
- First Cycle:
    - Throw objects far
    - Throw objects far with both the right and left hand
- Second Cycle:
    - Identify and aplly key elements of the throwing technique with a three-step run-up
    - Perform a sling throw from a standing position
- Third Cycle:
    - Identify and aplly key elements of the throwing technique with a five-step run-up
    - Hurl an object using a rotational movement
    - Observe key elements of throwing and hurling in classmates and provide feedback
    - Identify and aplly key elements of javelin throwing or rotational throwing

### Pushing
- Third Cycle:
    - Push an object for distance using full-body extension
    - Identify key elements of shot put technique and apply them during the push
    - Push a shot put far and observe key technique elements in classmates and provide feedback
